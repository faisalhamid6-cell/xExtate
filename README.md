# xExtate — Your Command Center 🧭

Welcome! This isn't just a folder of code — it's your **command center**: a home base where
you tell Claude Code what you want, and it gets done *the same reliable way every time*.

You are the founder / product person here. You don't need to be a developer. Your job is to
**say what you want in plain words**. Claude's job is to do it, explain it simply, write down
the "recipe" so it's repeatable, and remember things about your business so everything
**compounds** over time.

## 📂 What's in here (and why)

| Folder / File | What it's for | Think of it as... |
|---|---|---|
| `GETTING-STARTED.md` | Step-by-step "explain it like I'm 10" guide | Your instruction manual — **read this first** |
| `CLAUDE.md` | Instructions Claude reads automatically every session | The house rules Claude always follows |
| `sops/` | Standard Operating Procedures — saved "recipes" for repeatable tasks | Your cookbook |
| `knowledge-base/` | Durable facts about your business | Claude's long-term memory |
| `projects/` | Your little tools (each gets its own folder) | Your toolbox |

## ▶️ Want to see something work right now?

You already have a working tool. Run this one line (copy-paste it):

```bash
python3 projects/daily-report/daily_report.py
```

It reads a messy task list and turns it into a tidy daily report. That's your first win. ✅

## 🌱 The big idea: compounding

Every time we do something useful, we don't throw it away — we **save it**:
- A repeatable task → becomes an **SOP** in `sops/`.
- A useful fact about your business → goes in `knowledge-base/`.
- A handy tool → lives in `projects/`.

So next month you're not starting over. You're building on everything that came before.
