# SOPs — your recipe book 📖

**SOP** stands for *Standard Operating Procedure*. That's a fancy phrase for a **recipe**: a
written, step-by-step way to do a task so it comes out the same every time — no matter when you
do it or who does it.

## Why we keep these

So you never have to re-figure-out how something is done. We solve it once, write it down here,
and repeat it perfectly forever. This is a big part of how your command center **compounds**.

## How to use this folder

- Each procedure is one file, e.g. `add-a-new-tool.md`.
- To create a new one, copy `_TEMPLATE.md`, rename it, and fill in the blanks.
- Easiest of all: just ask Claude — *"Write this up as an SOP"* — after we finish a task.

## What's here now

- `_TEMPLATE.md` — the blank fill-in-the-blanks template.
- `add-a-new-tool.md` — example SOP: how we add a brand-new tool to `projects/`.
